# Boutique Coffee Shop Operations & Waste Optimization Dashboard

## Project Overview
This project provides a Business Intelligence (BI) web application built using Python and Streamlit. It processes transaction records from **Coffee Shop Sales.xlsx** to monitor real-time KPIs, analyze peak morning rush hours, evaluate product popularity, and provide strategic recommendations to mitigate perishable food/milk waste.

## Dataset Source
* **Dataset Name:** Coffee Shop Sales.xlsx (Transactions Sheet)
* **Description:** Contains historical point-of-sale transaction logs including timestamps, quantities, product categories, store locations, and revenues.

## Project Structure
- `app.py`: Main Streamlit web application script handling data extraction and frontend visualization.
- `requirements.txt`: Python package dependencies.
- `Coffee Shop Sales.xlsx`: Local database containing transaction logs.
- `Project_Report.docx`: Detailed conceptual documentation and UI output screenshots.
- `README.md`: Project documentation file.

## How to Run Locally
1. Ensure Python is installed on your system.
2. Place `Coffee Shop Sales.xlsx` in the same directory as `app.py`.
3. Install the required libraries using terminal:
   ```bash
